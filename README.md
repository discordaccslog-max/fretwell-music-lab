# Fretwell Music Lab

Storefront and practice room for Fretwell Music Lab: interactive music theory and ear-training tools for guitar and piano players. Static HTML, CSS and JavaScript with no runtime dependencies besides Google Fonts. All sound is synthesized in the browser; all exercises are generated from theory rules.

Live site: https://fretwell-music-lab.vercel.app/ (hosted on Vercel). A copy is also served by GitHub Pages at https://discordaccslog-max.github.io/fretwell-music-lab/; its canonical links point to the Vercel address.

## Before you sell

1. **Checkout links.** Open `js/products.js` and paste each product's checkout URL into its `checkoutUrl` field. The buy button appears on that product page automatically; while the field is empty no button is shown.
2. **After-payment redirect.** Set each checkout to send buyers to that product's thank-you page:

   | Product | Thank-you page |
   | --- | --- |
   | Note Reader | `/thank-you/note-reader/` |
   | Interval Ear Trainer | `/thank-you/interval-trainer/` |
   | Scale & Mode Explorer | `/thank-you/scale-explorer/` |
   | Chord Builder & Ear Trainer | `/thank-you/chord-builder/` |
   | Rhythm Lab | `/thank-you/rhythm-lab/` |
   | Foundations Bundle | `/thank-you/foundations-bundle/` |
   | Progression Lab | `/thank-you/progression-lab/` |
   | Jazz Harmony Studio | `/thank-you/jazz-harmony/` |
   | Melodic Dictation Studio | `/thank-you/melodic-dictation/` |
   | Atelier Edition | `/thank-you/atelier/` |

   Prefix each with `https://fretwell-music-lab.vercel.app` (or your own domain).
3. **Support email.** Put your address in `js/site-config.js` (`supportEmail`). It then appears on the Contact page and in the footer, and each tool shows a "Report a problem" link. While empty, none of these are shown.

## How license keys work

Keys look like `FRET-ET-7KQ4M-X9D2P-H6TR`: a product code, ten random characters and a four-character checksum, using an alphabet without 0, O, 1, I or L. Thank-you pages generate a key in the browser; the unlock page checks the format and checksum in the browser and saves valid keys in local storage. A Foundations Bundle key (`FB`) unlocks all five Foundations tools. There is no server, so keys cannot be revoked, and anyone who knows a thank-you page address can generate keys for that product. To send a replacement key to a customer, open the product's thank-you page yourself and copy the key it shows.

## Project layout

- `index.html`, `products/`, `about/`, `faq/`, `contact/`, policy pages, `unlock/`, `thank-you/`, `404.html` — generated pages (do not edit by hand; edit the templates)
- `practice/` — the practice room (installable progressive web app) and its manifest
- `js/core/` — music theory, synthesis, audio scheduling, notation, instruments, voice leading, melody and rhythm generation, license keys
- `js/tools/` — one module per practice room tool, loaded only when opened
- `js/app/` — practice room shell, storage, staff editor
- `js/pages/` — storefront page scripts and product demos
- `scripts/build.mjs` — page templates; `scripts/content-*.mjs` — page copy; `scripts/make-icons.mjs` — icons and social image
- `sw.js` — service worker (generated by the build)
- `tests/` — automated tests

## Hosting on Vercel

`vercel.json` runs `node scripts/build.mjs` on every deploy, serves the project root, adds trailing slashes (the pages use relative links), sets a few security headers and stops browsers caching `sw.js`. During Vercel builds the Privacy Policy names Vercel as the host. To use your own domain, add it in the Vercel project settings and set the `SITE_URL` environment variable (for example `https://yourdomain.com/`) so canonical links, social previews and the sitemap use it. Deploy manually with `vercel deploy --prod`.

## Commands

```bash
node scripts/build.mjs        # regenerate pages, sitemap, robots.txt and the service worker
node --test "tests/*.test.js" # theory, voice leading, generators, license keys, synthesis tuning
node scripts/check-site.mjs   # links, anchors, placeholder text, metadata, copy rules, contrast
node scripts/serve.mjs        # local server at http://localhost:8123/fretwell-music-lab/
```

Run the build after changing page copy, prices in `js/products.js` (the pages also update prices from that file at runtime), or any file the practice room uses, so the service worker picks up the new version.

## Notes

- Fonts load from Google Fonts, which receives visitors' IP addresses when serving them; the Privacy Policy says so. The site uses Geist and Geist Mono (SIL Open Font License). For stricter EU privacy you can self-host both and drop the Google Fonts link.
- Notation glyphs are original SVG drawings, not a font.
- The site never uses cookies, analytics, the microphone or the camera.
